# K-Direction

Public website for **K-Direction**, a recording label focused on cultivating and supporting talent.

This app is standalone. It does not share code, auth, or data with Rect Sound. It replaces the old Wix site at [kdirectionartistry.wixsite.com/k-direction](https://kdirectionartistry.wixsite.com/k-direction).

## Run it

```bash
cd k-direction
npm install
npm run dev
```

Open [http://127.0.0.1:3100](http://127.0.0.1:3100).

## Content

Roster, news, and contact copy live in `content/`. Swap files in `public/artists/` to update portraits.

## Pages

Home, Artist, Events, News, Contact, About, Careers — the same map as the Wix site, without empty Wix template leftovers.

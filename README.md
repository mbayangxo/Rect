# K-Direction

First site on **Kebu / Alkebulan**. Brand: **K-DIRECTION / K-DIRECTION CORP.**

Upload these files to https://github.com/mbayangxo/Kebu at **`sites/k-direction`**.

Do not merge this Rect export branch into Rect `main`. It is only a copy for Kebu.

## Run (after it is on Kebu)

```bash
cd sites/k-direction
cp env.example .env
npm install
npm run db:setup
npm run dev
```

Vercel: import **Kebu**, Root Directory `sites/k-direction`.
